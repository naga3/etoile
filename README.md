# 仮に咲くエトワール（etoile）

長押しでためて跳び、回りながらティアラを集めるバレリーナのゲーム。TypeScript と Vite。

遊ぶ：https://naga3.github.io/etoile/

もとは [naga3-mini-games](https://github.com/naga3/naga3-mini-games) の `src/games/spinning-jump-tiara`。そこから lab（小さな実験の置き場）に切り出し、作り直して単独のリポジトリにした。naga3-mini-games 時代の履歴は元のリポジトリにある。

## 遊び方

長押しで膝を曲げてためる（ためている間は時間が止まる）。離すと跳び、空中でくるくる回る。スペース・Enter・↑ キーでもよい。空中で押したまま着地すると、すぐ次のために入る（連続ジャンプ）。

難易度はタイトル画面で選ぶ（← → キーとスペースでもよい）。イージーは、ためている間に跳ぶ軌道や高さの目安が出る。ノーマルは目安も床の踏み切りの印も出ず、弧の形と高さを見て自分で合わせる。最高記録は難易度ごとに残る。

画面は 960×540 の横長で固定。どの端末でも同じ見え方になるよう、ウィンドウに合わせて拡大縮小し、余りは帯で埋める。

## ステージ

序曲・第一幕・第二幕・第三幕・終幕の 5 場面、ティアラは全 151 個。弧のティアラは「その位置から、その力で跳んだときの通り道」に置いてあり、踏み切りと力が合えば一回の跳躍でまとめて取れる（全部取ると Brava!）。

- 序曲・第一幕：イージーでは、床に踏み切りの印（バミリ）があり、ためている間に軌道が全部見える
- 第二幕から：イージーでも印が消え、見えるのは高さの目安だけになる
- 第三幕・終幕：高さの違う連続ジャンプ

並びは `src/course.ts`、跳躍の数値は `src/constants.ts`。結果は取った割合でパリ・オペラ座の階級（カドリーユ〜エトワール）になる。

## 音

音はすべてブラウザの中で合成している（Web Audio、音のファイルなし）。旋律はチェレスタ風の音で鳴らす。

| 場面 | 曲 |
|---|---|
| 序曲 | くるみ割り人形「小序曲」 |
| 第一幕 | くるみ割り人形「花のワルツ」 |
| 第二幕 | 眠れる森の美女「ワルツ」（ガーランド・ワルツ） |
| 第三幕 | 白鳥の湖「情景」 |
| 終幕 | くるみ割り人形「金平糖の精の踊り」 |
| カーテンコール | オルゴール（オリジナル） |

曲はどれもチャイコフスキー作でパブリックドメイン。旋律の音は flutetunes.com のフルート譜の MIDI を参考に確かめた。伴奏はこちらで和音を決めて組んだもので、譜面の配置はそのまま使っていない。譜面は `src/audio/songs.ts`、楽器と効果音は `src/audio/audio.ts`。

ティアラを取るとその曲の調の音が鳴り、一回の跳躍で続けて取るほど音が上がる。左上のスピーカーか M キーで消音する。

## 起動

```sh
npm install
npm run dev
```

`npm run build` で型検査と `dist/` の書き出しをする。main に push すると GitHub Actions が同じビルドをして GitHub Pages に公開する（`.github/workflows/pages.yml`）。
