# 砧に咲くエトワール（spinning-jump-tiara）

長押しでためて跳び、回りながらティアラを集めるバレリーナのゲーム。TypeScript と Vite。

もとは [naga3-mini-games](https://github.com/naga3/naga3-mini-games) の `src/games/spinning-jump-tiara`。共通ファイル 4 つ（`src/common`）と一緒に、単独で動く形に切り出した。履歴は元のリポジトリにある。

## 起動

```sh
cd spinning-jump-tiara
npm install
npm run dev
```

`npm run build` で型検査と `dist/` の書き出しをする。
